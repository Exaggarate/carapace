# Carapace NovitaAI provider

Official Carapace provider plugin for NovitaAI's OpenAI-compatible API.

## Install

```sh
carapace plugins install @carapace/novita-provider
carapace gateway restart
```

## Docs

See `docs/providers/novita.md` in the Carapace repository, or the published
