# Carapace GMI Cloud Provider

Official Carapace provider plugin for hosted GMI Cloud models through an
OpenAI-compatible API.

Install from Carapace:

```bash
carapace plugins install @carapace/gmi-provider
carapace gateway restart
```

Configure a GMI Cloud API key, then select models with refs such as
`gmi/openai/gpt-5.6-sol`.
