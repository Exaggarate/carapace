# OpenCode Zen Carapace provider

Official Carapace provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
carapace plugins install @carapace/opencode-provider
carapace gateway restart
```

## Docs

See `docs/providers/opencode.md` in the Carapace repository, or the published
docs at `../../docs/providers/opencode.md`.
