# Carapace OpenCode Go Provider

Official Carapace provider plugin for the OpenCode Go model catalog.

OpenCode Go is bundled with Carapace for this release; no separate plugin
installation is required.

Configure `OPENCODE_API_KEY` or `OPENCODE_ZEN_API_KEY`, then select an
`opencode-go/...` model.

See <../../docs/providers/opencode-go.md> for setup and the current
model catalog.
